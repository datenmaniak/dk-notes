## Infraestructura donde se puede implementar los orquestadores 

- Hardware fisico
- MV
- Instalaciones locales
- Nube publicas e Hibridas

## Donde se puede implementar K8s

- Estacion de trabajo:   Hipervisor o entorno de ejecucion
- Centro de datos
- Instancias en la nube:
	- AWS Elastic Compute Cloud (EC2)
	- MV de Google Compute Engine (GCE)
	- DigitalOcean Droplets
	- Servidores virtuales de IBM
	- OpenStack, etc


## Soluciones de orquestacion en la nube

Administrado como servicios (KaaS)

Ejemplos de KaaS:

- Amazon Elastic Kubernetes Services (EKS)
- Azure Kubernetes Service (AKS)
- DigitalOcean Kubernetes
- Google Kubernetes Engine (GKE)
- IBM Cloud Kubernetes Service
- Oracle Container Engine for Kubernetes
- VMWare Tanzu Kubernetes Grid
